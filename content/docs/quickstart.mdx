wappa is a set of npm packages. They are ESM only and need Node 20 or newer, so your
project needs `"type": "module"` in its `package.json`.

## Scaffold a project

The fastest path. The scaffolder asks which transport and provider you want, then writes a
ready project with the right dependencies pinned.

```bash
npm create wappa-agent my-bot
```

Skip the prompts with flags:

```bash
npm create wappa-agent my-bot -- --transport baileys --provider anthropic --yes
```

It generates `package.json`, `tsconfig.json`, a wired `src/index.ts`, `.env.example` and a
README. It does not run `npm install` for you:

```bash
cd my-bot
npm install
cp .env.example .env   # then fill in your keys
npm run build
npm start
```

## Add wappa to an existing project

Pick one transport and one provider. `@wappajs/core` is always required, and `zod` is what
you write tool schemas with.

```bash
npm install @wappajs/core @wappajs/baileys @wappajs/anthropic zod
```

| You want | Package |
| --- | --- |
| Personal number, QR login | [`@wappajs/baileys`](https://www.npmjs.com/package/@wappajs/baileys) |
| Official Meta Cloud API | [`@wappajs/cloud-api`](https://www.npmjs.com/package/@wappajs/cloud-api) |
| Twilio WhatsApp (BSP) | [`@wappajs/twilio`](https://www.npmjs.com/package/@wappajs/twilio) |
| Claude | [`@wappajs/anthropic`](https://www.npmjs.com/package/@wappajs/anthropic) |
| GPT, or any OpenAI-compatible server | [`@wappajs/openai`](https://www.npmjs.com/package/@wappajs/openai) |

## Your first bot

A personal WhatsApp number, logged in by QR code, answering with Claude and one tool:

```ts title="src/index.ts"
import { Agent, Bot, defineTool } from '@wappajs/core';
import { BaileysTransport } from '@wappajs/baileys';
import { AnthropicProvider } from '@wappajs/anthropic';
import { z } from 'zod';

const agent = new Agent({
  instructions: 'You are a helpful assistant reachable over WhatsApp. Keep replies short.',
  provider: new AnthropicProvider(), // reads ANTHROPIC_API_KEY from the environment
  tools: [
    defineTool({
      name: 'get_time',
      description: 'Get the current date and time.',
      parameters: z.object({}),
      execute: () => new Date().toString(),
    }),
  ],
});

const bot = new Bot({ transport: new BaileysTransport(), agent });

await bot.start(); // prints a QR code, scan it with WhatsApp on your phone
```

Run it:

```bash
export ANTHROPIC_API_KEY=sk-ant-...
npx tsc && node dist/index.js
```

Scan the QR code that appears in the terminal with WhatsApp on your phone
(Settings, then Linked devices, then Link a device) and message the linked number. Auth
state persists in `./wappa-auth`, so the QR scan is only needed once.

<Callout type="warn" title="Baileys is an unofficial client">
  Great for prototypes, personal bots and internal tools, but running one on a number you
  care about carries a ban risk and sits outside WhatsApp's Terms of Service. For
  production, use the [Cloud API](/docs/transports/cloud-api) or
  [Twilio](/docs/transports/twilio) transport.
</Callout>

## Working from a clone

Only needed if you want to change the framework itself:

```bash
git clone https://github.com/sifenfisaha/wappajs.git
cd wappajs
npm install
npm run build          # tsc -b, builds every package's dist/
npm test               # vitest run, all offline
```

The repo is an npm workspace, so you can add your bot under `examples/` and it will link
against the local packages instead of the published ones. Releases are cut with
`npm run release`, documented in
[RELEASING.md](https://github.com/sifenfisaha/wappajs/blob/main/RELEASING.md).

## Environment variables

| Variable | Used by |
| --- | --- |
| `ANTHROPIC_API_KEY` | `AnthropicProvider` (SDK default when `apiKey` not passed) |
| `OPENAI_API_KEY` | `OpenAIProvider` (SDK default when `apiKey` not passed) |
| `WHATSAPP_ACCESS_TOKEN`, `WHATSAPP_PHONE_NUMBER_ID`, `WHATSAPP_VERIFY_TOKEN`, `WHATSAPP_APP_SECRET` | your Cloud API bot config, see [Cloud API](/docs/transports/cloud-api) |
| `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_WHATSAPP_NUMBER`, `TWILIO_WEBHOOK_URL` | your Twilio bot config, see [Twilio](/docs/transports/twilio) |
